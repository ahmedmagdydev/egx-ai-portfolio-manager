## Purpose and use

This matrix preserves the material requirements in `../EGX_AI_Portfolio_Manager_Implementation_Guide.md` while assigning each requirement to the implementation-ready documentation suite defined by `C:\Users\ahmed\.devin\plans\plan-3b7d69bff26bb0b0.md`. The guide is the product brief. Planned documents refine it but must not weaken its deterministic-data, safety, or no-automated-trading boundaries. A row is complete only when its owning document exists, the expected artifacts are implemented, and the listed evidence is retained or reproducibly generated.

## Traceability maintenance gate

For each implementation pull request or phase exit:

1. Reference one or more matrix IDs in the change description and tests.
2. Update the owning contract/runbook before or with behavior changes.
3. Retain reproducible evidence (test command/output, fixture version, manual demo record, or review checklist).
4. Add a matrix row when a guide requirement is split into a new independently verifiable contract; never delete a safety or deterministic-boundary row without an explicit accepted decision record.
5. At release, audit all IDs: documentation owner present, artifact implemented, evidence current, and no deferred capability represented as available.
